# COORESUNTOL E.S.P. — Sitio corporativo + PQRS

Proyecto estático para GitHub Pages. Incluye sitio corporativo y formulario PQRS conectado a Web3Forms.

## Configuración

La Access Key de Web3Forms ya está configurada en `index.html`. No se utiliza Google Apps Script, Google Cloud ni n8n.

## Correo de destino

El formulario debe estar configurado en Web3Forms para enviar a: `cooresuntol2803@gmail.com`.

## Publicar en GitHub Pages

1. Sube todo el contenido de esta carpeta al repositorio.
2. Conserva las carpetas `css`, `js`, `img` y `documentos`.
3. En GitHub: Settings → Pages → Deploy from a branch → selecciona la rama y carpeta `/root`.
4. Abre la URL de GitHub Pages y realiza una prueba de PQRS.

## Archivos

- `index.html`: página completa y formulario PQRS.
- `css/styles.css`: diseño corporativo oscuro y responsive.
- `js/script.js`: menú móvil y envío AJAX del formulario.
- `img/`: coloca aquí logo, fotografías y documentos PDF.
- `documentos/`: disponible para documentos adicionales.

## Adjuntos

Esta versión usa Web3Forms en modalidad gratuita y no promete carga de archivos adjuntos. El formulario no incluye un campo de archivos para evitar ofrecer una función que el plan gratuito no cubra.
